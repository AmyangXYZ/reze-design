# Reze Design 使用手册

[English](https://github.com/AmyangXYZ/reze-design/blob/main/docs/manual/en.md) · **简体中文** · [日本語](https://github.com/AmyangXYZ/reze-design/blob/main/docs/manual/ja.md)

## 场景

拖入 `.pmx` 文件夹或 `.zip` 载入模型，拖入 `.vmd` 载入动作，拖入音频文件配乐。

**场景**标签页管理灯光、调色、背景与相机。**材质**标签页把材质分组，并为每组指定着色器图。

全部在浏览器中通过 WebGPU 运行，编辑过程不会上传任何文件。

## 预设

调色、背景特效与着色器图都在各自的库中。编辑后会成为你的本地草稿。

发布草稿即可分享。每次发布都是一个不可变版本，已使用它的场景不会随之改变。

## 发布场景

**分享**会把你上传的模型、动作与音频打包成一个压缩包，并以永久链接发布整个作品。借物表为必填——请写明模型、动作与音乐的作者。
