# Reze Design ユーザーマニュアル

[English](https://github.com/AmyangXYZ/reze-design/blob/main/docs/manual/en.md) · [简体中文](https://github.com/AmyangXYZ/reze-design/blob/main/docs/manual/zh.md) · **日本語**

## シーン

`.pmx` フォルダか `.zip` をドロップしてモデルを読み込みます。`.vmd` でモーション、音声ファイルで音楽を追加します。

**シーン**タブはライト・グレード・背景・カメラ、**マテリアル**タブはマテリアルのグループ分けとシェーダーグラフの割り当てです。

すべてブラウザ上の WebGPU で動作します。編集中にアップロードされるものはありません。

## プリセット

グレード・背景エフェクト・シェーダーグラフはそれぞれのライブラリにあります。編集するとローカルの下書きになります。

下書きを公開すると共有されます。公開ごとに不変のバージョンが作られ、既に使っているシーンが変わることはありません。

## シーンの公開

**共有**すると、アップロードしたモデル・モーション・音声が一つの書庫にまとめられ、固定リンクで公開されます。クレジットは必須 — モデル・モーション・音楽の作者を明記してください。
