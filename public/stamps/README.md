# Stamp sound

The footsteps `lib/stamps.ts` plays when a dancer's foot lands. `heels.wav` is
a sprite: 0.45-second slots, one recorded step per slot, softest first. Cut by
`scripts/stamp-sounds.py`, which says how and which steps.

The source is released under **Creative Commons 0** (public domain,
https://creativecommons.org/publicdomain/zero/1.0/). No credit is required;
it is given because it is deserved:

"01-15 Footsteps, Tile, Female Heels, Slow Pace.wav" by SpliceSound,
https://freesound.org/people/SpliceSound/sounds/218294/

Cut from Freesound's preview file (OGG). The WAV original is behind a free
login under the same licence; point `scripts/stamp-sounds.py` at it to re-cut
from lossless.
